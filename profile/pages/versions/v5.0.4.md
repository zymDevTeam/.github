# Release Notes - v5.0.4 🚀
_28 de mayo de 2026_

Esta versión de parche (v5.0.4) corrige un problema en el componente de procesos de Mi proceso, eliminando un método redundante de configuración de la fuente de datos.

---

## 📋 Mi proceso

### Optimización del Componente de Procesos
- **Eliminación de Código Redundante:**
  - Remoción del método redundante `setupDataSource()` en el componente de procesos para simplificar y limpiar la inicialización y el manejo de la fuente de datos.
